# Projeto: Combate à Violência Doméstica

## Como rodar localmente

1. Clone o repositório
2. Crie ambiente virtual: `python3 -m venv venv`
3. Ative: `source venv/bin/activate`
4. Instale dependências: `pip install -r requirements.txt`
5. Rode: `python3 app.py`
6. Acesse: http://localhost:5000

## Tecnologias
- Python 3.x
- Flask
- SQLite
- Bootstrap 5
